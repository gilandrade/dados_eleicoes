03b · Download dos resultados

Baixa do CDN do TSE os zips que a etapa 04 lê, para dados/01_bruto/{ano}/. Fica em R porque o CDN devolve 403 ao requests do Python. Pula o que já estiver em disco.

  • Ano geral (2018, 2022, 2026): votacao_secao_{ano}_BR.zip (Presidente).
  • Ano municipal (2020, 2024): um votacao_secao_{ano}_{UF}.zip por UF (26, sem DF) — não existe _BR nesses anos.
  • Nos dois casos, detalhe_votacao_secao_{ano}.zip (aptos e comparecimento por seção) e consulta_cand_{ano}.zip (candidatos e siglas dos partidos).

baixar_com_retry <- function(url, destino, tentativas = 3) {
  if (file.exists(destino)) {
    return(invisible(destino))
  }
  parcial <- paste0(destino, ".part")
  for (tentativa in seq_len(tentativas)) {
    resultado <- tryCatch(
      {
        request(url) |>
          req_user_agent("dados_eleicoes (CEM/USP)") |>
          req_perform(path = parcial)
        TRUE
      },
      error = function(e) {
        message(sprintf("Tentativa %d/%d falhou: %s", tentativa, tentativas, conditionMessage(e)))
        FALSE
      }
    )
    if (isTRUE(resultado)) break
    if (tentativa < tentativas) Sys.sleep(2^tentativa)
  }
  if (!isTRUE(resultado)) stop("Não foi possível baixar ", url)
  file.rename(parcial, destino)
  invisible(destino)
}

for (arquivo in arquivos_tse) {
  baixar_com_retry(file.path(TSE_CDN_BASE, arquivo), file.path(BRUTO_DIR, basename(arquivo)))
}
